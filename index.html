自建服务器一键部署脚本 (支持自定义域名 / 无域名 nip.io 证书)

内置 Caddy 2 自动 ACME (Let's Encrypt + ZeroSSL 双重自动签发)，确保 HTTPS 环境完整启用 PWA 离线能力

1. 无域名一键部署（自动获取公网 IP 并签发 <IP>.nip.io HTTPS 证书）
适合只有云服务器公网 IP、没有购买域名的场景（需开放 80 / 443 端口）
curl -fsSL https://raw.githubusercontent.com/elysianki4225-png/mcxor/main/deploy.sh | sudo bash -s -- --nip
2. 自定义域名一键部署（自动签发域名 TLS 证书）
请先将域名 A 记录解析至服务器 IP，替换下方 mc.example.com
curl -fsSL https://raw.githubusercontent.com/elysianki4225-png/mcxor/main/deploy.sh | sudo bash -s -- --domain mc.example.com
3. Docker Compose 容器化一键部署
仓库内已提供 Dockerfile 与 docker-compose.yml，支持环境变量指定域名或 nip.io
git clone https://github.com/elysianki4225-png/mcxor.git && cd mcxor && sudo ./deploy.sh --mode docker --nip
